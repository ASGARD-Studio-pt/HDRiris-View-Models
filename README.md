# HDRiris View AI Model

This repository hosts the optional AI model downloaded by
[HDRiris View](https://github.com/ASGARD-Studio-pt/HDRiris-View).

The application manages the download automatically and verifies it before use.
AI analysis runs locally; HDRI files and library data are not uploaded for
processing.

Model packages and checksums are available on the
[Releases page](https://github.com/ASGARD-Studio-pt/HDRiris-View-Models/releases).
Manual installation is not required.

this repository.
